# Profit Analysis

## Objective

To analyze company profit and identify the factors affecting profit.

## Tools Used

* MySQL
* Excel
* Power BI
* Python
* Statistics

## Key Analysis

* Sales and profit analysis
* State-wise performance analysis
* Expense analysis
* Data cleaning and transformation
* Dashboard creation

## Key Findings

* New York had the highest performance.
* California had the lowest performance.
* R&D Spend showed a strong relationship with profit.

## Project Outcome

Created an interactive Power BI dashboard to analyze sales, profit, and business performance.
